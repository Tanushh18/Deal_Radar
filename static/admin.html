Deal fetching

How the server pulls new deals out of the Telegram channels listed under Sources.

Automatic fetching

…

New posts usually arrive within seconds through the live listener; on top of that the server re-reads every channel on a timer. Pause stops that timer (e.g. while you fix something) — the site keeps showing the deals it already has.

⏸ Automatic syncing is paused — the site is showing what it already has. "Sync now" still works.

Sync now reads every channel once, right away — handy after adding a channel. Works even while paused.

How often to fetch deals

…

How often the server re-reads every source channel. New posts usually arrive within seconds anyway via the live listener; this is the backup sweep.

Manual — a fixed gap you choose. The server sticks to it no matter how busy things are.

min

Auto — the server decides every cycle. It goes faster when live deals run low, when many people are on the app/site, or when channels are posting a lot; it slows down when things are quiet. It always backs off if Telegram rate-limits. You set the fastest and slowest it may go.

Switching between Manual and Auto takes effect on the next cycle — no restart needed.

What users see

Controls for the order of deals and the sale calendar on the website and app.

Show on top

…

Deals matching this rule always come first on the website and app — in every sort, home row, trending and category. Nothing is hidden: other deals just follow below. In a typed search the rule only gives a boost, so exact matches still win.

Picking a ready-made preset saves it straight away. To make your own, change the fields below and press Save rule.

Notifications

Phone pushes and posts to your own Telegram channel.

Automatic notifications

…

Decides which deal pushes phones get on their own, and how many.

Needs the latest server update — this card works once the new server is deployed.

Manual — today's behaviour: a couple of hot-deal pushes at random moments (the card below), capped per hour, never in quiet hours.

Auto — the server decides what goes out and how much:
  1. Crazy deals — exceptional finds (lowest price ever at 70%+ off, or top-scored) go out soon after they appear, at most N a day.
  2. Best deal of the moment in prime windows (morning, lunch, evening); fewer on quiet days.
  3. "Come back" nudges — only to people who haven't opened the app in N days, at most once every N days, stopping after N tries.
Each phone shows them at the hour that person is usually active. Nothing is sent in quiet hours (… IST).

    Sources

    Where deals come from: one Telegram account and the channels it reads.

    Reader Telegram account

    …

    This one account reads every channel below for all visitors. Visitors never sign in. You only need to log in again if the pill above says the session expired.

    Connect / reconnect the account

    Save this once: copy it into Render → Environment as TELEGRAM_SESSION so the reader survives restarts (the free plan wipes local data). It is full access to this Telegram account — never share it.

    Channels

    Every channel the reader account follows on Telegram is read automatically. Block any you don't want on the site — blocked channels stay blocked. Refresh from Telegram re-checks which channels the account has joined; use it after joining or leaving one in the Telegram app.
